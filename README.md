# 🧮 Age Calculator

A simple web-based **Age Calculator** built using **HTML, CSS, and JavaScript**.  
It allows users to select their birth date and calculates their **exact age in years, months, and days**.

---

## 🚀 Features
- Automatically prevents selecting a future date.
- Displays accurate age in years, months, and days.
- Lightweight and runs entirely in the browser.
- Works on desktop and mobile devices.

---

## 🧱 Technologies Used
- **HTML** – structure of the page  
- **CSS** – styling and layout  
- **JavaScript** – logic to calculate age
